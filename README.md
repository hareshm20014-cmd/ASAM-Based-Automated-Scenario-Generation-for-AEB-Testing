Project 1 - ASAM-Based Automated Scenario Generator for AEB Testing

AIM - To build a complete python pipeline that converts a JSON defined environmental and vehicle parameter file into a structured ASAM OPENSCENARIO compliant file for scenario testing. The test is conducted for an AEB scenaio against the defined test metrics - showing the scenario based testing workflow. 

Objective - 
1. Learning to parse,validate and structure a JSON data using python for use as scenario input parameters 
2.Undersntad and apply ASAM OPENSCENARIO standard to construct a logical scenario flow  ( storyboard -story-Act -Manuever-Event -Action) 
3.Implement a Basic AEB (car-to-CAr rear stationary) scenario with parameters such as firction,speed,trigger distance. 
4.Build a lightweight kinematic simulaotor to execute the scenario and evaluate pas/fail criteria (TTC,Minimum gap,collision)
